# Working calm — calm-desktop

calm-desktop inherits calm from the suite; it does not restate the rules.

## Governing law lives elsewhere

- `~/Projects/calm` (GitHub `therealshakil/calm`), read live from `~/.claude/calm-live`:
  - `CONSTITUTION.md` — the Articles and banned patterns. Supreme.
  - `docs/identity.md` — the look: monochrome ink on paper, one clay accent, the locked faces, almost no motion.
  - `docs/calm-language.md` — the voice.
  - `CLAUDE.md` — how to be while you build.

When a choice here conflicts with the calm Constitution, the choice loses.

## How we work here

- Build Gate: two-way (a setting, a colour step) → proceed, report after; one-way (a new desktop, a new dep) → spec first, the person locks.
- Mechanics: absolute paths, one operation per command, no `cd`, no chaining or substitution; push after every commit.

## This project

The calm desktop for one Mint Cinnamon laptop. The themes are generated by `build-themes.py`, never
hand-edited; `apply.sh` replays every setting. Everything about Firefox (prefs and
stylesheets) lives in `~/Projects/calm-firefox`, a separate repo because it serves any Firefox; `apply.sh`
fetches and links it, and nothing Firefox is copied here.
